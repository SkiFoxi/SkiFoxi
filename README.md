## Проекты

### ActZero — система рекомендаций на Go + ElasticSearch
**Стек:** Go, ElasticSearch, PostgreSQL, Docker, HTML, CSS, JS  
Разработал сервис рекомендаций, который на основе выборов пользователя формирует персонализированные рекомендации удобных мест для открытия бизнеса.  
- Настроил индексацию данных в ElasticSearch с маппингом типов
- Реализовал REST API для получения рекомендаций с фильтрацией
- Написал поисковые запросы на ElasticSearch Query DSL (bool, filter, function_score)
- Запаковал сервис в Docker-контейнер, настроил docker-compose для связки app + elasticsearch
- Написал простой фронтенд для демонстрации

### Simple Bank — REST API для банковских операций
**Стек:** Go, PostgreSQL, Docker  
Разработал backend для банковского приложения с поддержкой пользователей, счетов и транзакций.  
- Спроектировал схему БД: таблицы users, accounts, transactions с внешними ключами и индексами
- Реализовал REST API для создания пользователей, пополнения/списания средств, переводов между счетами
- Написал юнит-тесты для большей части приложения
- Контейнеризировал приложение через Docker Compose

### API-Restaurant — MVP сервиса доставки еды
**Стек:** Go, PostgreSQL, Docker  
Разработал MVP платформы для заказа еды из ресторанов.  
- Спроектировал схему БД: таблицы с заказами, пользователями и ресторанами с их собственными блюдами
- Реализовал REST API для создания ресторана, заказа еды и отправки в выбранный пользователем ресторан
- Написал юнит-тесты для части приложения
- Контейнеризировал приложение через Docker Compose
- Реализовал архитектуру на чистой трёхслойной модели: Handler → Service → Repository с внедрением зависимостей
